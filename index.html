platform technology

how the hub is built — every layer, explained

The current platform combines a static web frontend with Supabase services and Paystack test-mode payment processing. The architecture is being expanded in measured, verifiable stages.

🖥️
1. Frontend and hosting

The public website is delivered as a responsive static web application.

  • HTML, CSS and JavaScript
  • GitHub repository and Pages hosting
  • Responsive layouts and navigation
🔐
2. Identity and access

Supabase Auth manages member identity and sessions.

  • Email and password authentication
  • Account profiles and roles
  • Row-level security policies
🗄️
3. Database

Supabase PostgreSQL stores structured platform data.

  • Profiles, recipes and community data
  • Courses, lessons and assessments
  • Enrolments, certificates and purchases
📁
4. Private file storage

Supabase Storage holds uploads and digital products.

  • Private product-file bucket
  • Seller and verified-buyer access rules
  • Time-limited signed downloads
💳
5. Payments

Paystack handles checkout and server-side verification.

  • NGN checkout in test mode
  • Verified transaction callbacks and webhooks
  • Live payments and seller settlement not yet enabled
💬
6. Community and notifications

Database policies and Supabase Realtime support member interactions.

  • Messaging and friend connections
  • In-app notifications
  • Reporting and moderation foundations

Users → Frontend → API → Backend → Database
Core protections include authenticated sessions, database row-level security, private file storage and server-side payment verification.
